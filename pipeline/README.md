# pipeline — 切分、抽取、入库

职责：把规范文本变成可检索单元与三元组。

- 切分：优先按结构（标题/条款/问答对），单块 300–800 字，overlap 10–15%，长文用父子块
- 元数据：来源、页码/章节路径、时间、密级/权限、实体 ID —— 缺元数据的 chunk 视为废块
- 抽取：LLM + JSON Schema 约束，规则词典兜底；实体消歧走别名表 + 聚类 + 人工审核队列
- 三元组：必须带证据句 + 出处；带 valid_from / valid_to
- 入库：以文档为单位 upsert，实体合并写 merge 日志，可回滚

幂等要求：同一输入重复跑，结果一致（除时间戳）。
