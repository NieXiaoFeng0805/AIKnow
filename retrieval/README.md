# retrieval — 检索编排

职责：把问题变成证据，再交给模型作答。

- 混合检索：BM25 + 向量，RRF 融合
- 重排：cross-encoder rerank，取 top-n 进上下文
- Query 处理：改写补全指代 / 多跳分解 / 路由（文档、SQL、图）
- 图扩展（启用图谱后）：命中实体做 1–2 跳或 PPR，取子图再回原文取证
- 输出：证据列表（chunk + 出处 + 分数），供上层生成与引用回链

硬规则：
- 检索不到就拒答，不硬编。
- 回答必须能点回原文对应位置。
- Text2SQL / Text2Cypher 只作为工具调用，不做主路径。
